# Triole IT - React Website

A modern, high-performance React application built for **Triole IT**, a leading technology solutions provider. This project is a migration from a WordPress site, optimized for speed, accessibility, and a premium user experience.

## ✨ Features

- **Premium Design:** Glassmorphic UI with neon purple and pink accents.
- **Fast Performance:** Built with Vite for ultra-fast HMR and build times.
- **Responsive Layout:** Fully optimized for mobile, tablet, and desktop devices.
- **Modern Animations:** Smooth transitions and interactions powered by Framer Motion.
- **SEO Optimized:** Semantic HTML5 and proper meta tag management.
- **Clean Architecture:** Component-based structure with a centralized design system.

## 🚀 Tech Stack

- **Framework:** [React 19](https://reactjs.org/)
- **Build Tool:** [Vite 8](https://vitejs.dev/)
- **Styling:** Vanilla CSS with custom utility classes.
- **Routing:** [React Router 7](https://reactrouter.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/)

## 🛠️ Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [npm](https://www.npmjs.com/)

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```bash
   cd triole-it
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

### Development

Run the development server:
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build

Create an optimized production build:
```bash
npm run build
```
The build artifacts will be stored in the `dist/` directory.

## 📂 Project Structure

- `src/assets/` - Static assets like logos and icons.
- `src/components/` - Reusable UI components (Navbar, Footer, etc.).
- `src/pages/` - Page components (Home, About, Services, Contacts).
- `src/index.css` - Global styles and design system tokens.
